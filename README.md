# Arrays

A collection of Java programs demonstrating common array operations and concepts.

## Programs

| File | Description |
|------|-------------|
| `ArrayBasic.java` | Basic array creation and element assignment |
| `ForEach.java` | Iterating through an array using the for-each loop |
| `LinearSearch.java` | Linear search to find an element in an array |
| `MaxofElement.java` | Finding the maximum element in an array |
| `Negative.java` | Printing all negative elements from an array |
| `OddandEven.java` | Modifying array elements based on index parity |
| `OutputInputArray.java` | Reading and printing array elements using Scanner |
| `PssingArraybyMethod.java` | Demonstrating pass-by-reference behavior of arrays (note: filename has a typo) |
| `ReverseArray.java` | Reversing an array in-place using two pointers |
| `SecondMax.java` | Finding the maximum and second maximum elements |
| `ShallowCopyDeepCopy.java` | Shallow copy vs deep copy of arrays |
| `SortArraybuiltin.java` | Sorting an array using `Arrays.sort()` |
| `SumofElement.java` | Calculating the sum of all array elements |

## How to Run

Compile and run any program using:

```bash
javac <filename>.java
java <classname>
```

For example:

```bash
javac LinearSearch.java
java LinearSearch
```
