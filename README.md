# Arrays

A collection of beginner-level Java programs demonstrating fundamental array operations and concepts.

## Programs

| File | Description |
|------|-------------|
| `ArrayBasic.java` | Basic array creation and element access |
| `ForEach.java` | Iterating through arrays using the enhanced for-each loop |
| `LinearSearch.java` | Linear search algorithm to find an element in an array |
| `MaxofElement.java` | Finding the maximum element in an array |
| `Negative.java` | Filtering negative elements from an array |
| `OddandEven.java` | Manipulating array elements based on odd/even index positions |
| `OutputInputArray.java` | Reading array input from the user and printing elements |
| `PssingArraybyMethod.java` | Demonstrating pass-by-reference behavior with arrays |
| `ReverseArray.java` | Reversing an array in place using the two-pointer approach |
| `SecondMax.java` | Finding the second largest element in an array |
| `ShallowCopyDeepCopy.java` | Difference between shallow copy and deep copy of arrays |
| `SortArraybuiltin.java` | Sorting an array using the built-in `Arrays.sort()` method |
| `SumofElement.java` | Calculating the sum of all elements in an array |

## How to Run

Compile and run any program using the Java compiler:

```bash
javac ArrayBasic.java
java ArrayBasic
```
